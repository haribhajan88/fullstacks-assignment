CSS Box-Sizing Comparison

Compare content-box and border-box.

Content-Box

Content Box

The specified width applies to the content. Padding and borders increase the total width.

CSS width: 200px

Border-Box

Border Box

The specified width includes the content, padding, and border.

CSS width: 200px

Key Difference

With content-box, total width equals content width plus left and right padding and borders. With border-box, the total width remains the specified width.
