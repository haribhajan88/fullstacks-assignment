Responsive Design Principles

Three important concepts for responsive websites.

Fluid Layouts

Fluid layouts use relative units so elements can adjust to available screen space. 

.container {
    width: 90%;
    max-width: 1200px;
    margin: auto;
}

Flexible Media

Flexible images and videos resize within their containing elements. 

img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Breakpoints allow styles to change when the viewport reaches a specific width. 

@media (max-width: 600px) {
    .container {
        padding: 10px;
    }
}
