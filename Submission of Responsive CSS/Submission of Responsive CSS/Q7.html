Responsive Design

Responsive web design makes a webpage adapt to different screen sizes. Flexbox, Grid, relative units, and media queries help create flexible layouts.

CSS Cheat Sheet

  • Flexbox: align items.
  • Grid: create columns and rows.
  • Media queries: change styles by screen width.
  • Clamp: create flexible font sizes.
