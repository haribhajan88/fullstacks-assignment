Responsive CSS Cheat Sheet

Important concepts for responsive web design.

Filters

Apply visual effects to images and elements.

filter: grayscale(100%);

Media Queries

Apply CSS rules according to screen size.

@media (max-width: 600px)

Responsive Design

Make layouts adapt to phones, tablets, and desktops.

width: 100%;

Typography

Use flexible font sizes for different screens.

font-size: clamp(1rem, 2vw, 2rem);

CSS Grid

Create flexible rows and columns.

grid-template-columns: repeat(2, 1fr);

Flexbox

Align and distribute items in a container.

display: flex;
